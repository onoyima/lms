Operations > System health.

**Exam-day performance**: candidates writing, answers saved per minute, response time, server errors, CPU and memory — for the last hour, day or week. Watch it during big sittings.

**Exam-hall network**: add each hall's switch, wireless access point and the internet router (address and port). Each is checked every minute; after three failures in a row it shows as *down* and ICT and exams officers are told. *Slow* means it answered but took over 300 ms. The page also shows how many approved exam computers in each hall are online.
