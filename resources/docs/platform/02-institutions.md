## Applications

Institutions apply from the public website. Before approving, **check they are genuine**: call the phone number, confirm the e-mail domain belongs to the institution. Approving creates the institution, starts the trial (30 days by default) and e-mails the administrator a link to set a password. Declining records the reason.

## Adding an institution directly

Institutions > Add institution — for signed contracts. Give the short name (its web address), domains, plan, billing cycle, trial days and the first administrator.

## On each institution's page

- **Subscription**: change plan or cycle, set an agreed price, issue a renewal invoice.
- **Contract details**: contacts and domains.
- **Modules**: switch a module on as an add-on or off, on top of the plan.
- **Suspend / restore**: reasons are *unpaid*, *institution asked*, *misuse*, *other*. Paying lifts only an *unpaid* suspension.
- **Invoices and payments**: record a bank transfer (check the statement first), cancel an unpaid invoice.
